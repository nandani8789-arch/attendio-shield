CS601: WEB TECHNOLOGY & CLOUD ARCHITECTURE

Dumka Engineering College · Department of Computer Science & Engineering
6th Semester · 3 Credits · Academic Year 2025-2026

Module 1: Modern Web Core & Semantic UI

HTML5 semantic architecture, CSS3 flexbox and grid systems, KaTeX, WebGL/Three.js 3D rendering in canvas, responsive viewport optimization, cross-browser compatibility.

Module 2: Client-side Engineering & Asynchronous JavaScript

ECMAScript 6+, DOM manipulation, Event delegation, Web APIs (Geolocation, Camera MediaDevices), Promise chaining, Fetch API, and client-side single page routing.

Module 3: Server-side Runtime & RESTful Backend

Node.js event loop, Express.js middleware pipelines, session management, secure cookies, rate limiting, and cryptographic hashing (bcrypt).

Module 4: Embedded Database & Geofence Architecture

SQLite / PostgreSQL design, relational mapping, Haversine spatial spherical distance calculations, and real-time QR token rotation algorithms.
