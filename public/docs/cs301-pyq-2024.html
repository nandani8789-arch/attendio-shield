Q1. Compulsory Section (Answer ALL 7 parts): 7 × 2 = 14 Marks
(a) Define Big-O, Big-Omega (Ω), and Big-Theta (Θ) notations. State the tightest bound for Binary Search on a sorted array of size n.
(b) Why is a Circular Queue preferred over a Linear Queue implemented using a single fixed array? State the condition for Queue Overflow in a circular array of size N.
(c) What is the maximum number of nodes in a Binary Tree of depth k? What is the minimum depth of an n-node binary tree?
(d) Differentiate between Internal Sorting and External Sorting with at least one practical example of each.
(e) Convert the following infix expression to postfix notation using an explicit operator stack:
(A + B) * (C - D) / E ^ F
(f) Define an AVL tree. What are the permissible values of Balance Factor (BF) for each node in a strictly height-balanced tree?
(g) What is a Hash Collision? Briefly explain how Linear Probing resolves collision compared to Separate Chaining.

  • Insert a node at a specified arbitrary position k.
  • Delete the last node (tail) of the linked list.
  • Reverse the singly linked list in a single pass without extra memory (in-place reversal).
(b) Evaluate the following postfix expression step-by-step using a stack showing the stack contents at each operand and operator read:
6   2   3   +   *   12   4   /   -
Q3. Binary Search Trees & AVL Rotations: 7 + 7 = 14 Marks

Show the resultant tree and perform In-order, Pre-order, and Post-order traversals. Delete node 30 and draw the updated tree.

14, 20, 11, 24, 18, 16, 26, 12, 19. Show rotations at each unbalance.
